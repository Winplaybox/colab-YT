# Background music

Har mood folder mein 2-3 mp3 daalo. Pipeline script ke mood ke hisaab se ek track chunega, voice ke time music apne aap dheema ho jayega (ducking).

```
music/mystery/      rahasya, mandir mysteries
music/epic/         yuddh, shakti, bade moments
music/devotional/   bhakti, darshan, aarti feel
music/calm/         shaant kathayein
```

**Sirf copyright-free music:** YouTube Studio → Audio Library → filter "Attribution not required". Download karke yahan daalo. Kisi film/gaane ka music mat daalna, Content ID claim aayega aur us video ki earning chali jayegi.

Agar koi folder khaali hai, toh pipeline baaki folders se le lega. Sab khaali → sirf voice.
